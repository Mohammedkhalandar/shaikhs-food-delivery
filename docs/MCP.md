# Tooling and MCP

This session exposes local command/file tools, collaboration tools, web search and computer-use/browser tooling, plus connected-tool discovery for GitHub, document sessions and other services. Availability is not proof of an authenticated project connection. No database MCP server was inspected or used. No new MCP server was installed.

Repository implementation uses ordinary local Node/Prisma tools. Git operations cannot proceed against this extracted folder until a repository exists. Browser inspection should use the available computer-use tooling and record the actual rendered outcomes; tests that were not run must remain pending.

Use least privilege. Never send `.env`, session cookies, customer details or production database credentials to untrusted tools. Do not install untrusted servers automatically. Production actions and public deployment require authorization; safe local inspection and reversible edits are authorized by the project request.
